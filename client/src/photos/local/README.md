# Local photos

The homepage photo strip reads images from this folder and nowhere else. It renders nothing until a real photo is here and listed in `alts.ts`.

Do not add stock images, downloaded city skylines, handshakes, or generic storefronts.

## Add a photo

1. Put a file you or Charles own in this folder. Use `jpg`, `jpeg`, `png`, `webp`, or `avif`.
2. Add the filename to `alts.ts` with alt text. A file without an alt entry stays hidden.

## Alt text

Name the real place and what is in the frame. Include Mt Pleasant, Charleston, or the neighborhood (I'On, Park West, Point Hope, Carolina Park, Shem Creek, Old Village, Daniel Island, Isle of Palms, Sullivan's Island, West Ashley, James Island, Summerville).

If Charles is in the photo, say what he is doing and where.

Good: `Charles Stovall at Shem Creek in Mt Pleasant, SC, walking the waterfront before a buyer meeting.`

Weak: `Smiling businessman` or `Charleston skyline`.
